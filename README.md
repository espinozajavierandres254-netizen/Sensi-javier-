# Sensi Javier

Proyecto Sensi Javier para iOS.

## Contenido

- Panel de acceso mediante key.
- Pantalla de inicio Sensi Javier.
- Contador de tiempo de la key.
- Compatibilidad con Free Fire y Free Fire Max.
- Interfaz optimizada para dispositivos móviles.
